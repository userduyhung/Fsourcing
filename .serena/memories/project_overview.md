# Project Overview

## Project Purpose
**Fsourcing** - A global B2B marketplace landing page application that connects buyers with verified suppliers worldwide. The project is a React-based single-page application showcasing:

- Supplier directory and verification system
- Product sourcing capabilities  
- Dashboard for sourcing analytics
- Global network of manufacturers and suppliers
- AI-powered search functionality

## Project Type
- Static landing page / marketing website
- B2B marketplace presentation layer
- No authentication or routing implemented yet (static content only)
- Built with modern React + TypeScript stack

## Key Features Displayed
- Hero section with call-to-action
- Featured suppliers showcase
- Service/feature highlights
- Dashboard preview section
- Contact and company information
- Professional business-focused design

## Target Audience
- Businesses looking for global suppliers
- Manufacturers wanting to showcase products
- B2B procurement professionals
- International trade companies
